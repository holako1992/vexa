- **The dashboard exports transcripts as text, Markdown, Word, SubRip, WebVTT and PDF (#1685).**
  The meeting page's **Export** dialog downloads the transcript as it is shown, speaker names
  included: `.txt`, `.md`, `.docx`, `.srt` and `.vtt` are built in the browser, **Copy as
  Markdown** puts the same Markdown on the clipboard, and **PDF** opens the browser's print dialog
  over a print layout that keeps the header, summary and transcript and drops the app's controls.
